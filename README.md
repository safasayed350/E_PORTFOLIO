## 🎨 Design Philosophy & Aesthetic

The portfolio embodies a tailored **Baby Pink, Soft Lavender, and Crisp White** design language crafted specifically for academic evaluation:

- **Soft Lavender (`#A855F7`, `#8B5CF6`, `#EDE9FE`):** Represents technical structure, calm focus, and modern elegance.
- **Baby Pink (`#EC4899`, `#F472B6`, `#FCE7F3`):** Provides warm, vibrant accents and approachable contrast.
- **Deep Slate Violet (`#1C1829`, `#4A4458`):** Guarantees high contrast readability complying with WCAG AAA accessibility guidelines.
- **Subtle Glassmorphism:** Layered frosted card surfaces with backdrop blurs and ambient pastel glow shadows.
- **Tasteful Micro-Interactions:** Smooth hovering elevations, scroll spy navigation, tabbed code switching, and one-click clipboard copying.

## 📂 Project Architecture

The codebase is structured into modular CSS and vanilla JavaScript with zero external runtime dependencies or heavy build tooling, ensuring instant loading and effortless deployment:

```text
E_PORTFOLIO/
├── index.html                    # Semantic HTML5 document (accessible, SEO-ready)
├── style.css                     # Master stylesheet (imports modular stylesheets)
├── README.md                     # Academic submission documentation
└── assets/
    ├── css/
    │   ├── variables.css         # Theme tokens (colors, gradients, shadows, radii)
    │   ├── base.css              # Reset, typography, containers, custom scrollbar
    │   ├── components.css        # Buttons, cards, badges, terminal window, timeline
    │   ├── layout.css            # Section grids, hero layout, bento cards, responsive rules
    │   └── animations.css        # Keyframes, floating chips, scroll reveal transitions
    └── js/
        └── main.js               # Scroll spy, mobile drawer, interactive tabs, copy email
```

## 💻 How to Run Locally

Because this project is built using pure modern web standards without complex bundlers, running it is instantaneous:

### Option 1: Direct Browser
Simply double-click `index.html` or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Python Server (Recommended)
In PowerShell or terminal:
```bash
python -m http.server 3000
```
Open `http://localhost:3000` in your web browser.

## ☁️ Deployment

### Deploying to Vercel
This repository is configured for zero-configuration instant deployment on Vercel:
1. Import `safasayed350/E_PORTFOLIO` into your [Vercel Dashboard](https://vercel.com/new).
2. Keep default settings (Static Site).
3. Click **Deploy**.

### Deploying to GitHub Pages
1. Go to **Settings > Pages** in your GitHub repository.
2. Under **Branch**, select `main` and root `/`.
3. Click **Save**.
